# 家族カレンダー

家族の予定をみんなで管理するための、無料で使えるシンプルなカレンダーWebアプリです。

**プログラミングの知識がなくても、この手順どおりに進めれば、あなた専用のカレンダーアプリをスマホのホーム画面に置いて使えるようになります。**

> ⚠️ このアプリはビルド不要の素の HTML / CSS / JavaScript のみで作られています。`npm install` のようなインストール作業は一切不要です。ブラウザで直接開くか、後述のGitHub Pagesで公開するだけで動作します。

## 主な機能

- 月表示・週表示・日表示の切り替え（週表示・日表示は縦軸=日付、横軸=時間のタイムライン形式）
- 複数日にまたがる予定（宿泊・旅行など）の作成にも対応
- 土曜日は水色、日曜日・日本の祝日はピンクで表示（祝日は自動計算）
- 家族メンバーの登録・編集・削除と、色分け表示
- よく使う予定（テンプレート）の登録と、予定作成時のプルダウン選択
- 終日／時間指定、担当する家族（複数選択可）、メモ入力に対応
- 予定のコピー機能（似た予定をすぐに複製できます）
- 表示する家族メンバーを絞り込む機能
- スマートフォン・タブレット・PCに対応したレスポンシブデザイン
- （任意）Firebaseと連携して、家族のスマホ・PC間で予定をリアルタイム共有

## 動作環境

- インターネットに接続できるWebブラウザ（Google Chrome、Safari、Microsoft Edgeなど最新のもの）があれば、パソコン・スマートフォン・タブレットのどれでも動作します
- 特別なソフトのインストールは不要です

## 使い始めるための3ステップ

### ステップ1: 自分のGitHubアカウントにコピー（Fork）する

1. このページの右上にある **「Fork」** ボタンをクリックします
   （GitHubアカウントをまだお持ちでない方は、先にアカウント作成が必要です。作成手順は下の「GitHubアカウントの作り方」を参照してください）
2. 「Create a new fork」画面が表示されるので、内容はそのままで **「Create fork」** ボタンをクリックします
3. 数秒待つと、あなた自身のGitHubアカウントにこのアプリの複製（コピー）が作成されます

### ステップ2: GitHub Pagesで公開する

Forkしたことで、あなたのアカウントに `family-calendar`（またはそれに似た名前）というリポジトリができています。

1. そのリポジトリのページを開き、上部メニューの **「Settings」** タブをクリック
2. 左側メニューの **「Pages」** をクリック
3. 「Build and deployment」の **Source** で `Deploy from a branch` を選択
4. **Branch** を `main`、フォルダは `/ (root)` のままにして **Save** をクリック
5. 数十秒〜数分待つと、ページ上部に「Your site is live at `https://あなたのユーザー名.github.io/リポジトリ名/`」と表示されます

> 🔒 GitHub Pagesを無料で使うには、リポジトリが **Public（公開）** である必要があります。Fork直後はPublicになっているはずですが、もし「Upgrade or make this repository public to enable Pages」と表示された場合は、Settings → General → 一番下の「Danger Zone」→「Change repository visibility」からPublicに変更してください。

### ステップ3: スマホから使う

1. 発行されたURL（`https://あなたのユーザー名.github.io/リポジトリ名/`）をスマホのブラウザで開きます
2. ブラウザのメニューから「ホーム画面に追加」を選択すると、アプリのようにホーム画面から起動できるようになります
   - iPhone（Safari）: 共有ボタン（□に↑）→「ホーム画面に追加」
   - Android（Chrome）: 右上の「︙」メニュー →「ホーム画面に追加」

これで、あなた専用の家族カレンダーの完成です。まずは右上の「⚙ 設定」から、家族メンバーの名前や色を登録してみてください。

## データの保存について

このアプリはサーバーを持たない静的サイトです。家族メンバー・テンプレート・予定のデータは、
**ブラウザの localStorage** に保存されます。

- 同じブラウザ・同じ端末であれば、閉じても再度開いてもデータは消えません。
- ただし、後述の「オンライン共有」を設定しない限り、**別の端末やブラウザとはデータが同期されません**
  （例：スマホで入力した予定はPCのブラウザには表示されません）。

## 複数端末での共有設定（Firebase・任意）

家族のスマホ・PC間で同じ予定をリアルタイムに共有したい場合は、無料のFirebaseプロジェクトを設定できます。
設定しない場合はこれまで通り、端末ごとの独立した保存（localStorageのみ）で動作します。

> ⚠️ 設定した内容（後述のAPIキー等）は、**あなた専用のFirebaseプロジェクト**を作成した場合にのみ使ってください。他人が作成したFirebaseプロジェクトの値を使い回すと、その人の予定データと同じ場所にデータが保存されてしまいます。

### 1. Firebaseプロジェクトを作成する

1. https://console.firebase.google.com/ をブラウザで開き、Googleアカウントでログイン
2. 「プロジェクトを追加」（画面表示によっては「Firebaseプロジェクトを設定して開始」）をクリックし、好きなプロジェクト名（例: `my-family-calendar`）を入力して作成
   （Googleアナリティクスは不要なのでオフのままで構いません）

### 2. Firestore Database を有効化する

1. 作成したプロジェクトの画面で、左メニュー「構築」（画面表示によっては「Database と Storage」）→ **Firestore**（**Firestore Database**）を開く
2. 「データベースの作成」をクリック
3. 「エディションを選択」と表示された場合は **Standard エディション** を選び、次へ（Enterpriseは大規模向けの高度なオプションのため不要です）
4. ロケーションは任意（日本から使うなら `asia-northeast1` 等）を選び、次へ
5. セキュリティルールは「本番環境モード」のまま作成してOK（ルールは後で設定します）

### 3. 匿名認証を有効化する

1. 左メニュー「構築」（画面表示によっては「セキュリティ」）→ **Authentication** を開く
2. 「始める」→ 「Sign-in method」タブ
3. 一覧から **匿名** を選び、有効にして保存

### 4. セキュリティルールを設定する

Firestore Database → 「ルール」タブを開き、以下の内容に書き換えて公開してください。
これにより「匿名ログイン済みの人だけ」がデータを読み書きできるようになります。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{familyCode} {
      allow read, write: if request.auth != null;
    }
  }
}
```

> 注意: これは「共有コード（familyCode）を知っている人なら誰でも読み書きできる」簡易的な仕組みです。
> パスワードのように扱い、第三者に漏らさないよう共有コードを管理してください。

### 5. Webアプリを登録し、設定値を取得する

1. プロジェクトのトップ画面（歯車アイコン→プロジェクトの設定）を開く
2. 「マイアプリ」で `</>`（ウェブ）アイコンをクリックしてアプリを登録（Firebase Hostingは不要なのでチェックしなくてOK）
3. 表示される `firebaseConfig` の中の値（`apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`）を控える

これらの値はFirebaseの仕組み上、外部に見られても問題ない値です（実際のアクセス制御はステップ4のセキュリティルールが担っています）。

### 6. アプリ側で接続する

1. 家族カレンダーアプリの **⚙ 設定** を開く
2. 一番下の「オンライン共有（複数端末で同期）」セクションに、5.で控えた値を入力
3. 「共有コード」に家族で共通の合言葉を入力（「自動生成」ボタンでランダムな文字列を作ることも可能）
4. 「接続する」を押す
5. **2台目以降の端末**では、同じFirebaseプロジェクトの値と**同じ共有コード**を入力して接続してください

以降は、いずれかの端末で予定を追加・編集すると、他の端末にもリアルタイムに反映されます。
共有をやめたい場合は、設定画面の「切断してこの端末だけで使う」から解除できます。

## ローカルでの動作確認（開発者向け）

`index.html` をブラウザで直接開くだけで動作します。より確実に動かす場合は、簡易サーバーを立てて確認してください。

```bash
# 例：Pythonがある場合
python3 -m http.server 8000
# その後 http://localhost:8000/ を開く
```

## ファイル構成

```
index.html               画面のHTML本体
css/style.css            スタイル（レスポンシブ対応）
js/utils.js              日付・時間・色に関する共通処理
js/holidays.js           日本の祝日計算（振替休日・国民の休日を含む）
js/storage.js            localStorageへの保存・読み込み、色パレット
js/state.js              家族メンバー・テンプレート・予定のデータ管理（CRUD）
js/sync.js               Firebase Firestoreを使ったオンライン共有（任意設定）
js/filter.js             表示する家族メンバーの絞り込み（端末ごとの表示設定）
js/modal.js              モーダルダイアログの共通土台
js/views/month.js        月表示
js/views/timeline.js     週表示・日表示（タイムライン）
js/views/eventForm.js    予定の新規作成・編集・コピー・詳細確認フォーム
js/views/settings.js     設定画面（家族メンバー・テンプレート・オンライン共有）
js/views/memberFilter.js 表示メンバー絞り込みボタン・ドロップダウン
js/app.js                全体のコントローラー（表示切替・ナビゲーション）
```
